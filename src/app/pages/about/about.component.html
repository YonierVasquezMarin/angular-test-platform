Acerca de este proyecto

Atlas de países es una aplicación de prueba para recorrer las herramientas principales de Angular, las prácticas de SEO y el rendimiento medible con Lighthouse.

Herramientas de Angular

  • Componentes standalone, router con carga perezosa y detección de cambios zoneless.
  • NgRx con store, effects, entity y DevTools. RxJS en los effects y en la búsqueda.
  • HttpClient con un interceptor de errores y formularios reactivos en Buscar y Planificar.
  • Render híbrido: páginas públicas prerenderizadas y favoritos o notas en el cliente.

SEO y URLs amigables

Cada página pública tiene un título, una descripción, una URL canónica y datos estructurados. Las fichas usan el nombre en español, por ejemplo /paises/colombia.

Core Web Vitals

  • LCP: el HTML llega prerenderizado y la bandera de la ficha se pide con prioridad.
  • INP: la búsqueda espera 300 ms antes de filtrar, para no recalcular en cada tecla.
  • CLS: banderas y esqueletos reservan su tamaño, y el aviso del formulario también.

Accesibilidad y Lighthouse

La interfaz usa regiones con nombre, un enlace para saltar al contenido, etiquetas en los controles y mensajes de error asociados a cada campo. Para auditarla, abre Chrome DevTools, entra en Lighthouse y ejecuta Performance, Accessibility, SEO y Best Practices.
